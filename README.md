# face_blur_tool

動画内の顔を自動検出して、自然なぼかし(境界のない楕円ぼかし)を入れるツール。
OpenCV(YuNet顔検出)+ ffmpeg(VideoToolboxハードウェアデコード/エンコード)で、
M3 / 8GBメモリのMacでも4K・長尺素材をほぼ等速で処理できるように作られています。

## セットアップ(初回のみ)

すでに完了しています。次回以降は下記の「使い方」からでOKです。

```bash
cd ~/Desktop/face_blur_tool
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## 使い方

```bash
cd ~/Desktop/face_blur_tool
source venv/bin/activate

python blur_faces.py 入力動画.mp4 出力動画.mp4
```

これだけで、動画全体を通しで処理して顔をぼかします。音声はそのままコピーされます。

## まず短い範囲で試す(推奨)

40〜60分の本編をいきなり処理する前に、気になるシーン(人が多い場面など)だけ
切り出してぼかし具合を確認するのがおすすめです。

```bash
# 開始5分の位置から30秒間だけ処理して確認
python blur_faces.py 入力動画.mp4 テスト出力.mp4 --start 300 --duration 30
```

## よく使う調整オプション

| オプション | 内容 | デフォルト |
|---|---|---|
| `--strength` | ぼかしの強さ。**顔サイズに対する割合**(0〜1)。大きいほど強い | 0.5 |
| `--pad` | 顔まわりの余白率(大きいほど広く隠す。髪や後頭部まで覆いたくない場合は下げる) | 0.22 |
| `--confidence` | 検出の敏感さ(下げると小さい/遠い顔も拾うが誤検出も増える) | 0.5 |
| `--detect-width` | 検出処理に使う解像度(下げると速いが精度は落ちる) | 1280 |
| `--max-missed` | 検出が一瞬外れてもぼかしを保持するフレーム数(チラつき対策) | 10 |
| `--cut-threshold` | シーンカット検知の感度(小さいほど敏感。`0`で無効化) | 18.0 |
| `--bitrate` | 出力ビットレート(Mbps)。元素材と同等以上を目安に | 100 |

`--bitrate`: VideoToolboxの画質指定(`-q:v`)は実際の書き出しで信頼性が低く、
元素材(4K高品質素材で50Mbps前後)に対して出力が6Mbps程度まで落ちてしまう
問題が確認されたため、ビットレートを直接指定する方式にしています。
YouTubeの4K(30fps)推奨アップロードビットレートは35〜45Mbpsなので、
デフォルトの100Mbpsであれば十分な余裕があります。容量を抑えたい場合は
`--bitrate 70`程度まで下げても実用上問題ありません。

`--cut-threshold`: カット編集した動画をそのまま処理すると、場面が切り替わった直後も
古い位置にぼかしが少し居座ってしまうことがあります。これはフレーム間の変化量を見て
「大きく変わったらカットとみなしトラッキングをリセットする」ことで防いでいます。
もし逆に、激しいパン・ズームのある地続きのシーンで誤ってリセットされてしまう場合は、
値を大きく(例: 30〜40)してみてください。

`--strength`は絶対pxではなく顔サイズとの比率なので、遠くの小さい顔も近くの大きい顔も
同じ「濃さ」の見た目になります(遠い顔だけ粗くブロック状になる、ということが起きません)。

例: もう少し強くぼかしたい/余白を広げたい場合

```bash
python blur_faces.py 入力動画.mp4 出力動画.mp4 --strength 0.6 --pad 0.3
```

例: もっと自然に、輪郭だけ軽く隠したい場合

```bash
python blur_faces.py 入力動画.mp4 出力動画.mp4 --strength 0.35 --pad 0.15
```

## 長尺素材を分割して処理したい場合

```bash
python blur_faces.py 入力動画.mp4 part1.mp4 --start 0    --duration 1200   # 0〜20分
python blur_faces.py 入力動画.mp4 part2.mp4 --start 1200 --duration 1200   # 20〜40分
python blur_faces.py 入力動画.mp4 part3.mp4 --start 2400                  # 40分〜最後
```

後でつなげる場合(再エンコードなしで結合):

```bash
printf "file 'part1.mp4'\nfile 'part2.mp4'\nfile 'part3.mp4'\n" > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy 結合後.mp4
```

## ベンチマーク(このMac・4Kテスト映像での実測)

- 処理速度: 約1.0倍速(4K30fps映像をほぼ等速で処理)
- メモリ使用量: 約600MB前後(ピーク)
- → 60分の素材なら、だいたい60〜70分程度で処理が終わる想定です(人物の数や動きにより多少前後します)

## 動作の仕組み(メモ)

1. ffmpegがVideoToolboxでハードウェアデコード
2. 検出用に縮小したフレームでOpenCV(YuNet)が顔を検出
3. 簡易トラッカーがフレーム間で同一人物を追従し、検出が一瞬途切れても
   位置を保持(チラつき防止)してなめらかに動かす
4. 検出領域に、顔サイズに比例した半径のガウスぼかしをかけ(ブロック状にならず滑らか)、
   楕円のソフトマスクで境界線が目立たないように合成
5. ffmpegがVideoToolboxでハードウェアエンコードし、元の音声をそのまま結合
